# TaskFlow - Modern To-Do Web Application

TaskFlow is a clean, intuitive, and modern to-do list web application designed to help you organize daily tasks efficiently.

![TaskFlow Preview](https://raw.githubusercontent.com/bishwajeetoraon2003-gif/to-do-list-web-app/main/index.html) *(Preview locally by opening index.html)*

## Features

- **Add Tasks**: Quickly add tasks with title and priority tags (Low, Medium, High).
- **Inline Task Editing**: Edit any task in-place by clicking the edit icon or double-clicking the task text. Press <kbd>Enter</kbd> to save or <kbd>Esc</kbd> to cancel.
- **Completion Tracking**: Interactive checkbox with smooth animation, visual progress bar, and completion percentage.
- **Animated Deletion**: Delete tasks with a clean exit transition.
- **LocalStorage Persistence**: Tasks and theme preferences persist automatically in your browser across sessions.
- **Filters & Search**:
  - Filter by **All**, **Active**, or **Done**
  - Real-time instant search filtering
  - Quick "Clear Completed" action
- **Dark & Light Mode**: Sleek theme switcher with system preference detection and storage.
- **Modern Responsive Design**: Built with vanilla HTML5, CSS3, and modern typography (`Plus Jakarta Sans`). Zero external runtime dependencies.

## Getting Started

No build process or installation is required!

1. Clone or download this repository:
   ```bash
   git clone https://github.com/bishwajeetoraon2003-gif/to-do-list-web-app.git
   ```
2. Open `index.html` in your favorite web browser.

## Tech Stack

- **HTML5**: Semantic markup with accessibility considerations (`aria-*`).
- **CSS3**: CSS Custom Properties (variables), Flexbox, CSS Grid, Glassmorphism, and responsive breakpoints.
- **JavaScript (ES6+)**: Event delegation, DOM manipulation, and `localStorage` API.
